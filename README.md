# 凭证数据分析工具 / Voucher Data Analysis Tool

用 Python 标准库实现的凭证数据校验与分析工具,面向会计场景中常见的月结前检查工作。
不依赖任何第三方库,`python voucher_analysis.py` 即可运行。

## 背景

月结前的凭证复核通常在 Excel 里手工完成:筛选异常金额、透视表做科目汇总、
用 VLOOKUP 和银行流水核对。数据量大或需要每月重复时,手工操作既慢又容易漏。

本工具把这套流程固化成脚本,输入两个 CSV,一次运行输出五份报表。

## 功能

| 模块 | 说明 | 输出 |
|---|---|---|
| 数据校验 | 检查凭证号格式、金额缺失、负数标记 | 屏幕清单 |
| 月度汇总 | 按月统计笔数、合计、平均 | `monthly.csv` |
| 交叉汇总 | 月份 × 科目 双维度汇总 | `cross.csv` |
| 异常检测 | 按科目分别计算均值,标记超阈值记录 | `outliers.csv` |
| 银行对账 | 逐笔比对,识别三类差异 | `diff.csv` |

## 设计说明

**异常检测按科目分组设阈值,而非使用全局均值。**
不同科目的金额量级差异很大——差旅费的正常区间和办公费完全不同。
用全局均值会让小额科目的异常被大额科目掩盖:一笔 3000 元的办公费
(其科目均值的 12 倍)在全局阈值下不会被标记。

**对账用凭证号作键,而非按行号顺序比对。**
真实场景中两边的笔数和顺序都不一致,按位置配对会全面错位。
以凭证号建立字典后,比对与顺序无关,并且能自然地区分出
「只在账簿有」「只在银行有」两类差异。

**均值非正时跳过倍数比较。**
若某科目当期以冲销为主导致均值为负,「大于均值 3 倍」会退化为
「大于一个更小的负数」,几乎所有记录都会被误判为异常。

## 使用方法

准备两个 CSV 文件放在同目录下。

`data.csv`(账簿):

```
凭证号,日期,科目,金额,摘要
V001,2025-01-05,差旅费,1200,出差北京
V002,2025-01-08,办公费,350,打印纸
```

`bank.csv`(银行流水):

```
凭证号,金额
V001,1200
V002,350
```

运行:

```bash
python voucher_analysis.py
```

## 参数配置

在文件顶部调整:

```python
OUTLIER_TIMES = 3          # 异常阈值倍数
ENCODING = "utf-8-sig"     # 输出编码,utf-8-sig 保证 Excel 打开中文不乱码
```

## 环境

Python 3.8+,无第三方依赖。
